# Sales Bonus Calculator

## 📌 Описание проекта

Проектная работа по JavaScript из Практикума. Задача — реализовать обработку данных о продажах интернет-магазина и рассчитать бонусы для продавцов.

## 🎯 Цель

Разработать переиспользуемую функцию расчета бонусов по заданным метрикам и на её основе — набор конкретных вычислений для определения лучших продавцов.

## 🛠️ Задачи

- Реализовать универсальную функцию расчета бонусов (принимает массив функций).
- Написать функции для расчёта:
  -  Расчитать премии на основе ранжирования.
  - Сделать сортировку продавцов по прибыли.
  - Продавца, привлекшего клиента с наибольшим чеком.
  - Продумать обработку ошибок и отметьте проверки в коде.
  - Сформируйте итоговый отчёт по всем продавцам а так же топ 10.
- Вывести результаты в консоль.

## ⚙️ Технологии

- JavaScript (ES6+)
- HTML (запуск проекта в браузере)
- Без сборщиков, модулей и сторонних библиотек

## 📐 Функциональные требования

- Расчёт прибыли с товара — отдельная функция, передаваемая как параметр.
- Основная функция должна быть гибкой и расширяемой: поддерживать любые метрики и способы расчёта.
- Код должен быть отформатирован и сопровождён JS-Doc комментариями.

## ✅ Требования

- Код должен выполняться в любом современном браузере.
- Используются только стандартные возможности JavaScript.
- Поддержка автотестов.

## Инструкция по запуску
Открыть любым способом файл `index.html` в браузере. В консоли DevTools (CTRL+Shift+I) будет выведен рейтинг продавцов и рассчитанные бонусы.
Чтобы изменить выбранный датасет, необходимо в файле `index.html` изменить ссылку в строке:
```html
<script src="data/dataset_1.js"></script>
```
Доступны 3 примера дата-сетов:
- `data/dataset_1.js`
- `data/dataset_2.js`
- `data/dataset_3.js`
